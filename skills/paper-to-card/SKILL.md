# 文献表转网页卡片 Skill

## 用途

把一批学术文献从杂乱的参考文献列表整理成可检索、可追溯的网页卡片。适用于文献调研网站、课程项目展示和核验报告，不负责替代论文阅读。

## 输入

- 文献题名、作者、年份与来源平台。
- DOI 或原始论文链接。
- 需要网页支持的技术判断。
- 可选：现有 CSV、Markdown 综述或核验日志。

## 必做流程

1. **去重**：优先使用 DOI；没有 DOI 时使用规范化题名去重。
2. **确认存在性**：打开出版社、CVF、IEEE、ACM、OpenReview、NeurIPS Proceedings、SpringerLink 或 arXiv 原始条目。
3. **核对元数据**：题名、作者、年份、venue、页码、DOI 必须属于同一记录。
4. **区分版本**：分别标注预印本、会议录和期刊；不得把 arXiv 的 DataCite 标识写成会议或期刊 DOI。
5. **绑定论断**：卡片中的方法描述必须能回到摘要、方法或实验设置。
6. **记录不确定性**：无法确认的内容写入 `uncertainty`，不能用猜测补齐。
7. **写入 CSV**：按项目字段更新 `data/papers.csv`。
8. **页面复检**：刷新网站，检查统计、筛选、链接与移动端布局。

## CSV 字段

`id, year, title, status, venue, doi, tags, verification, url, notes`

其中：

- `status`：正式出版、会议录、预印本、预印本/会议或预印本/正式收录。
- `tags`：使用 `|` 分隔多个标签。
- `verification`：真实、软幻觉修正、引用缺口或待确认。
- `url`：优先放 DOI 解析地址或论文原始条目。
- `notes`：只写核验后能够支持的简短判断。

## 输出卡片模板

```markdown
### {{title}}
- 年份 / 状态：{{year}} · {{status}}
- 技术路线：{{tag}}
- DOI：{{doi_or_none}}
- 原始入口：{{url}}
- 核验结论：{{verification}}
- 支持的判断：{{supported_claim}}
- 尚不能确认：{{uncertainty}}
```

## 质量门槛

- 每张卡片至少有一个可访问的原始入口。
- 页面中的计数来自 CSV，不手工重复维护。
- “真实论文”与“引用完整”分开判断。
- 不把方法名、项目名或代码库名自动当作正式论文题名。
- 修改一行 CSV 后，页面对应记录和统计应同步变化。
